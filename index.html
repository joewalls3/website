01 About

Curious by default.
Technical on purpose.

I’m most at home where creative decisions meet technical systems: inside a control room, behind a console, or deep in a prototype that started as “what if?”

My work crosses live video, audio, broadcast engineering, robotics, software, aviation, and travel. The common thread is simple: make complicated things feel calm, clear, and dependable.

✦

04 How I work

Build for showtime,
not just demo time.

A cool idea is only useful if it survives the real world. I design around the operator, the edge cases, and the moment the pressure is on.

  1. 01

    See the whole system

    Map the people, gear, signals, constraints, and actual goal.

  2. 02

    Make complexity visible

    Turn the moving parts into a workflow a normal person can follow.

  3. 03

    Test like it’s live

    Break it safely, fix the weak points, document it, then run the show.
